# 🚀 Nova AI Chatbot

**Nova AI** is an intelligent AI-powered chatbot built with Node.js, Express.js, and Google's Gemini API.

## 🌐 Live Demo

👉 https://nova-ai-chatbot-w4av.onrender.com

## 📂 GitHub Repository

👉 https://github.com/SMSRABON/nova-ai-chatbot

## ✨ Features

- 🤖 AI-powered conversations
- ⚡ Fast responses with Gemini Flash Lite
- 🎓 Tutor Mode
- 💻 Coding Assistant Mode
- ✍️ Writing Assistant Mode
- 💬 Helpful Assistant Mode
- 📱 Responsive user interface
- 🔐 Secure API key configuration

- Render

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/SMSRABON/nova-ai-chatbot.git
```

2. Open the project folder:

```bash
cd nova-ai-chatbot
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file and add:

```env
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.5-flash-lite
```

5. Start the server:

```bash
npm start
```

6. Open:

```text
http://localhost:3000
```

## 🔒 Environment Variables

Never publish your real API key on GitHub.

Keep your `.env` file private and use environment variables on Render.
